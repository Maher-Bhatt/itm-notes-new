# Q1 (A). Select the correct option [3]

**1. If dy/dx = xy + y² with y(0) = 1, then using the R-K method the value of k₁ with step size 0.1 is:** (a) 0.1 · (b) 0.01 · (c) 0.0001 · (d) 0.0001
**Answer: (a) 0.1.** k₁ = h f(x₀, y₀) = 0.1 × (0·1 + 1²) = 0.1.

**Answer: (c).**

**1. Trapezoidal rule for six intervals.**

**∫ₐᵇ f(x) dx ≈ (h/2) [ (y₀ + y₆) + 2(y₁ + y₂ + y₃ + y₄ + y₅) ]**

**2. Using Descartes' rule of signs, the number of complex roots of x⁷ − 3x⁴ + 2x³ − 1 = 0.**
- f(x) signs: + − + − → **3 sign changes** → 3 or 1 positive roots.
- f(−x) = −x⁷ − 3x⁴ − 2x³ − 1: signs − − − − → **0 changes** → no negative roots. x = 0 is not a root.
- Degree 7, so complex roots = 7 − (3 or 1) − 0 = **at least 4** (4 or 6).

**3. Sufficient condition for convergence of the Gauss-Seidel and Gauss-Jacobi methods.**
The coefficient matrix must be **diagonally dominant**: in each row, |aᵢᵢ| ≥ Σⱼ≠ᵢ |aᵢⱼ|, with strict inequality for at least one row. Rearrange the equations to achieve this before iterating.

## Q2(e) Budan's theorem: number of roots of x³ − 3x² − 4x + 13 = 0 in [−3,−2], [−2,−1], [−1,0], [0,1], [1,2], [2,3].

f(x) = x³ − 3x² − 4x + 13, f′(x) = 3x² − 6x − 4, f″(x) = 6x − 6, f‴(x) = 6. V(x) = number of sign changes in (f, f′, f″, f‴).

| x | f | f′ | f″ | f‴ | V(x) |
|---|---|---|---|---|---|
| −3 | −29 | 41 | −24 | 6 | 3 |
| −2 | 1 | 20 | −18 | 6 | 2 |
| −1 | 13 | 5 | −12 | 6 | 2 |
| 0 | 13 | −4 | −6 | 6 | 2 |
| 1 | 7 | −7 | 0 | 6 | 2 |
| 2 | 1 | −4 | 6 | 6 | 2 |
| 3 | 1 | 5 | 12 | 6 | 0 |

Number of roots in (a, b) is V(a) − V(b) or less by an even number:
- [−3, −2]: 3 − 2 = **1 real root**.
- [−2, −1], [−1, 0], [0, 1], [1, 2]: 0 → **no roots**.
- [2, 3]: 2 − 0 = **2 or 0 roots**. Check: f(2.5) = −0.125 < 0 while f(2) = f(3) = 1 > 0, so there are **2 real roots** in (2, 3).

## Q3(a) Two iterations of Lin-Bairstow: quadratic factor x² + px + q of x⁴ − 8x³ + 39x² − 62x + 50, p₀ = q₀ = 0.

Synthetic division by x² + px + q: bₖ = aₖ − p bₖ₋₁ − q bₖ₋₂, cₖ = bₖ − p cₖ₋₁ − q cₖ₋₂, then solve
c₂ Δp + c₁ Δq = b₃ and (c₃ − b₃) Δp + c₂ Δq = b₄.

**Iteration 1 (p = 0, q = 0):** b = (1, −8, 39, −62, 50), c = (1, −8, 39, −62).
39Δp − 8Δq = −62 and 0·Δp + 39Δq = 50 → **Δp = −1.3268, Δq = 1.2821** → p₁ = −1.3268, q₁ = 1.2821.

**Iteration 2:** b = (1, −6.6732, 28.8642, −15.1488, −7.1041), c = (1, −5.3465, 20.4886, 18.8891).
Solving gives **Δp = −0.5789, Δq = 0.6150** → p₂ = −1.9057, q₂ = 1.8970.

Quadratic factor after two iterations: **x² − 1.9057x + 1.8970**. (Iterating further converges to x² − 2x + 2; indeed x⁴ − 8x³ + 39x² − 62x + 50 = (x² − 2x + 2)(x² − 6x + 25), giving roots 1 ± i and 3 ± 4i.)

## Q3(e) Heun's predictor-corrector: y at x = 0.1 for dy/dx = x² + y, y(0) = 1.

*The paper prints "step size 0.5", which overshoots x = 0.1; it is a misprint for **h = 0.05** (as in the end-semester paper).* With h = 0.05 (two steps):

Predictor yᵖ = yₙ + h f(xₙ, yₙ); corrector y = yₙ + (h/2)[f(xₙ, yₙ) + f(xₙ₊₁, yᵖ)], repeated until stable.
