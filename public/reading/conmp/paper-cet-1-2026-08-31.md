# Q1. Select the correct option [3]

**1. The convergence of which method is prone to the starting value?** (a) Regula-Falsi · (b) Newton-Raphson · (c) Bisection · (d) All
**Answer: (b) Newton-Raphson.**

**2. Find the odd one out:** (a) Bisection method · (b) Bolzano's method · (c) Midpoint method · (d) Regula-Falsi method
**Answer: (d) Regula-Falsi.** Bisection, Bolzano's method and the midpoint method are three names for the same interval-halving method; Regula-Falsi uses the chord (false position) instead of the midpoint.

**3. In the successive approximation method, for rapid convergence φ′(x) should be:** **Answer: (b) smaller than 1.**

**4. Which of the following is also known as the Newton-Raphson method?** (a) Chord method · (b) Tangent method · (c) Slope method · (d) Fixed-point method
**Answer: (b) Tangent method.**

**5. For a polynomial, Budan's theorem is used to estimate, within an interval, the number of:** (a) Complex roots · (b) Real roots · (c) Total roots · (d) Positive and negative roots
**Answer: (b) Real roots** (in a given interval [a, b]; Descartes' rule counts positive and negative roots).

**6. The Gauss-Seidel method converges faster than Gauss-Jacobi because:** **Answer: (c) it uses the latest available values.**

## Q2(a) List the rules for estimating errors.

Absolute, relative and percentage error; rounding to n decimals gives error ≤ ½ × 10⁻ⁿ; n significant digits gives relative error < ½ × 10⁻ⁿ⁺¹; errors add for sums/differences; relative errors add for products/quotients. Full answer: [CONMP CET-1 2025, Q2(b)](/library/conmp/paper-cet-1-2025-08-22#q2b-list-the-rules-for-estimating-errors).

## Q2(e) Derive the iterative formula for the Newton-Raphson method.

From Taylor's series f(x₀ + h) ≈ f(x₀) + hf′(x₀) = 0 → h = −f(x₀)/f′(x₀) → **xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ)**. Full derivation: [CONMP CET-1 2025, Q2(a)](/library/conmp/paper-cet-1-2025-08-22#q2a-derive-the-iterative-formula-for-the-newton-raphson-method).

## Q3(d) Quadratic factor x² + px + q of x⁴ − 3x³ + 20x² + 44x + 54 = 0, two Lin-Bairstow iterations.

The paper does not state the starting values; we take **p₀ = q₀ = 2** (the values used for this polynomial in the class tutorial).

**Iteration 1:** b = (1, −5, 28, −2, 2), c = (1, −7, 40, −68). Solving 40Δp − 7Δq = −2 and (−68 + 2)Δp + 40Δq = 2 gives **Δp = −0.0580, Δq = −0.0457** → p₁ = 1.9420, q₁ = 1.9543.

**Iteration 2:** b = (1, −4.9420, 27.6431, −0.0248, 0.0251), c = (1, −6.8840, 39.0575, −62.4212) → **Δp = −0.0007, Δq = −0.0005** → p₂ = 1.9413, q₂ = 1.9538.

Quadratic factor: **x² + 1.9413x + 1.9538** (the corrections are already tiny, so the factor has converged to about three decimals).
