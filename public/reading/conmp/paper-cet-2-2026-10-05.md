## Q2(c) Absolute error if X = 0.00545828 is (i) truncated (ii) rounded to three decimal (significant) digits.

Here "three decimal digits" means three significant digits (5, 4, 5):
- (i) Truncated: X₁ = 0.00545 → absolute error = 0.00545828 − 0.00545 = **0.00000828 = 8.28 × 10⁻⁶**.
- (ii) Rounded: X₁ = 0.00546 → absolute error = |0.00545828 − 0.00546| = **0.00000172 = 1.72 × 10⁻⁶**.

Rounding gives the smaller error.

## Q3(c) Viscosity of oil at 140° using Lagrange's formula.

Data: (110, 10.8), (130, 8.1), (160, 5.5), (190, 4.8); x = 140.
- L₀ = (140−130)(140−160)(140−190) / [(110−130)(110−160)(110−190)] = (10)(−20)(−50)/[(−20)(−50)(−80)] = 10000/−80000 = **−0.125**
- L₁ = (30)(−20)(−50)/[(20)(−30)(−60)] = 30000/36000 = **0.833333**
- L₂ = (30)(10)(−50)/[(50)(30)(−30)] = −15000/−45000 = **0.333333**
- L₃ = (30)(10)(−20)/[(80)(60)(30)] = −6000/144000 = **−0.041667**

v(140) = −0.125(10.8) + 0.833333(8.1) + 0.333333(5.5) − 0.041667(4.8)
= −1.35 + 6.75 + 1.833333 − 0.2 = **7.0333**.
