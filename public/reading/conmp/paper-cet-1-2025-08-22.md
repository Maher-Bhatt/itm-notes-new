# Q1 (A). Select the correct option [3]

**1. The convergence of which of the following methods is prone to the starting value?** (a) Regula-Falsi · (b) Newton-Raphson · (c) Bisection · (d) all
**Answer: (b) Newton-Raphson.** Bisection and Regula-Falsi always converge once a sign-change interval is chosen; Newton-Raphson may diverge from a poor x₀ or where f′(x) ≈ 0.

**2. If a number is correct to n significant digits, then the relative error is:** (a) ½·10ⁿ · (b) ½·10ⁿ⁻¹ · (c) ≤ ½·10⁻ⁿ · (d) < ½·10⁻ⁿ⁺¹
**Answer: (d)** relative error < ½ × 10⁻ⁿ⁺¹ (i.e. 1/(2·10ⁿ⁻¹)).

**3. In the successive approximation method, for rapid convergence the value of φ′(x) should be:** (a) larger than 1 · (b) smaller than 1 · (c) zero · (d) can have any value
**Answer: (b)** |φ′(x)| < 1 is required for convergence, and the smaller it is, the faster the convergence.

**1. If the permissible error is ε, the approximate number of iterations n needed for the bisection method?**
After n halvings the interval length is (b − a)/2ⁿ. We need (b − a)/2ⁿ ≤ ε, so **n ≥ [log(b − a) − log ε] / log 2**.

## Q2(a) Derive the iterative formula for the Newton-Raphson method.

Let x₀ be an approximation to a root of f(x) = 0 and let x₁ = x₀ + h be the exact root, so f(x₀ + h) = 0. Expand by Taylor's series:

f(x₀ + h) = f(x₀) + h f′(x₀) + (h²/2!) f″(x₀) + … = 0

Since h is small, neglect h² and higher powers: f(x₀) + h f′(x₀) = 0, so **h = −f(x₀)/f′(x₀)** (f′(x₀) ≠ 0).

Hence x₁ = x₀ − f(x₀)/f′(x₀), and in general

**xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ),  n = 0, 1, 2, …**

Geometrically, xₙ₊₁ is where the tangent to y = f(x) at (xₙ, f(xₙ)) cuts the x-axis, hence "method of tangents".

## Q2(b) List the rules for estimating errors.

1. **Absolute error:** Eₐ = |X − X₁| (true value X, approximate value X₁).
2. **Relative error:** Eᵣ = |X − X₁| / |X|; **percentage error** Eₚ = 100 · Eᵣ.
3. If a number is **rounded to n decimal places**, the absolute error ≤ ½ × 10⁻ⁿ.
4. If a number is **correct to n significant digits**, the relative error < ½ × 10⁻ⁿ⁺¹.
5. **Addition/subtraction:** the absolute error of a sum or difference ≤ the sum of the absolute errors: δ(X ± Y) ≤ δX + δY.
6. **Multiplication/division:** the relative error of a product or quotient ≤ the sum of the relative errors: δ(XY)/(XY) ≤ δX/X + δY/Y.
7. **General formula:** for u = f(x₁, …, xₙ), δu ≈ Σ |∂f/∂xᵢ| δxᵢ; for u = xᵐ, δu/u = m·δx/x.

## Q2(c) Find a real root of x³ − x − 1 = 0 correct to three decimal places by successive approximations.

f(1) = −1 < 0 and f(2) = 5 > 0, so a root lies in (1, 2). Write x = φ(x) = (1 + x)^(1/3).
φ′(x) = (1/3)(1 + x)^(−2/3) < 1 on (1, 2), so the iteration converges. Take x₀ = 1.5:

| n | xₙ | xₙ₊₁ = (1 + xₙ)^(1/3) |
|---|---|---|
| 0 | 1.50000 | 1.35721 |
| 1 | 1.35721 | 1.33086 |
| 2 | 1.33086 | 1.32588 |
| 3 | 1.32588 | 1.32494 |
| 4 | 1.32494 | 1.32476 |

The last two values agree to three decimals: **x ≈ 1.325** (exact root 1.32472).

## Q2(d) Percentage error (i) 625.483 approximated to three significant figures (ii) 75462 rounded off to four significant digits.

(i) 625.483 → **625**. Error = 0.483. Percentage error = 0.483/625.483 × 100 = **0.0772 %**.
(ii) 75462 → **75460**. Error = 2. Percentage error = 2/75462 × 100 = **0.00265 %**.
