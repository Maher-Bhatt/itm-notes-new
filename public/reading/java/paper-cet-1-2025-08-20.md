## Q3.4 Explain the Scanner class in Java.

`java.util.Scanner` reads and **parses** input (keyboard, file or string) into tokens separated by whitespace.
- Create: `Scanner sc = new Scanner(System.in);` (or `new Scanner(new File("data.txt"))`).
- Read methods: `nextInt()`, `nextDouble()`, `nextLong()`, `nextBoolean()`, `next()` (one word), `nextLine()` (whole line).
- Check methods: `hasNextInt()`, `hasNext()`, `hasNextLine()` to validate before reading.
- Close with `sc.close()`.
- Pitfall: after `nextInt()`, the newline stays in the buffer, so a following `nextLine()` returns an empty string; call an extra `nextLine()` first.
- Wrong type input throws `InputMismatchException`.

```java
import java.util.Scanner;

public class ScannerDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner("21 Asha 8.75\nComputer Engineering");
        int age = sc.nextInt();
        String name = sc.next();
        double cpi = sc.nextDouble();
        sc.nextLine();                         // consume the rest of line 1
        String branch = sc.nextLine();
        System.out.println(name + ", " + age + ", CPI " + cpi + ", " + branch);
        sc.close();
    }
}
```
Output: `Asha, 21, CPI 8.75, Computer Engineering`. (In an exam, use `new Scanner(System.in)`; a string source is used here so the run is reproducible.)

## Q4.1 (1) BankAccount with deposit(), withdraw() and display(). (2) Three integers in decreasing order.

**(1)**
```java
class BankAccount {
    private String holder;
    private double balance;
    BankAccount(String holder, double opening) { this.holder = holder; this.balance = opening; }
    void deposit(double amt) {
        if (amt > 0) balance += amt;
        else System.out.println("Invalid deposit");
    }
    void withdraw(double amt) {
        if (amt > balance) System.out.println("Insufficient balance for " + amt);
        else balance -= amt;
    }
    void display() { System.out.println(holder + " balance: " + balance); }
}

public class BankDemo {
    public static void main(String[] args) {
        BankAccount acc = new BankAccount("Riya", 1000);
        acc.display();
        acc.deposit(500);   acc.display();
        acc.withdraw(300);  acc.display();
        acc.withdraw(5000);
        acc.display();
    }
}
```

```

Riya balance: 1200.0
Insufficient balance for 5000.0
Riya balance: 1200.0
```

```java
    }
```
